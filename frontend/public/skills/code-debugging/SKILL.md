# Code Debugging Skill

Use LeetBug's code analysis and hint generation engine to find bugs, review algorithm edge cases, and run unit tests.

## Capabilities

- Inspecting failing test cases and edge cases
- Generating targeted hints with retrieved official documentation
- Automated code reviews and complexity analysis
- Debugging Python, JavaScript, and Java algorithmic solutions

## Endpoints

- API Base: `https://leetbug.nevatal.id/api`
- OpenAPI Specification: `https://leetbug.nevatal.id/api/openapi.json`
- API Documentation: `https://leetbug.nevatal.id/api/docs`
