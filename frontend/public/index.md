# LeetBug — Real-World Debugging Practice Platform

LeetBug is a hands-on debugging platform designed for software engineers to sharpen their troubleshooting, code investigation, and root-cause analysis skills across modern programming languages.

## Key Features

- **220+ Realistic Debugging Challenges**: Broken code bases covering runtime exceptions, subtle logic errors, distributed state failures, concurrency race conditions, and system design edge cases.
- **Multi-Language Support**: Debug across Python, Go, Java 17, C++17, and TypeScript/JavaScript in isolated sandbox containers.
- **Progressive Hinting & RAG Retrieval**: Multi-stage documentation hints powered by vector search over official language documentation.
- **AI-Directed Debugging & Evaluation**: AI debugging assistant and automated test harness asserting correct state and performance bounds.
- **Fourteen Problem-Solving Courses**: Structured tracks covering memory bugs, async timing issues, SQL transaction rollback errors, and microservice failure modes.
- **Community Learning**: Solution discussions, efficiency leaderboards, and detailed post-mortem writeups.

## How to Use LeetBug

1. **Select a Problem**: Browse challenges filtered by language, difficulty, and failure category.
2. **Reproduce the Bug**: Run public test suites to examine runtime traces, assertions, and memory dumps.
3. **Isolate and Fix**: Modify code in the built-in editor and run verification suites.
4. **Submit & Review**: Submit your fix to execute all private regression tests and view performance metrics.
